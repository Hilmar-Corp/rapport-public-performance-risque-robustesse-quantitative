# HilmarCorp — Dossier de références du rapport HC-RPT-PUB-001

## Objet

Ce dossier regroupe les références externes utilisées pour documenter les méthodes statistiques, les mesures de risque, les sources de données de marché et les standards techniques mentionnés dans le rapport public de performance, de risque et de robustesse quantitative de Nostra AI V5.246.

Les références externes ne constituent pas une validation indépendante de Nostra AI. Elles documentent l'origine ou la définition de méthodes, tests, standards et interfaces utilisés ou cités dans le rapport.

## Structure

- `REF-INDEX-001.md` — registre maître des références et correspondance avec les sections du rapport.
- `REF-METH-001.md` — références méthodologiques et statistiques.
- `REF-DATA-001.md` — sources de données de marché et provenance documentaire.
- `REF-TECH-001.md` — standards et documentation technique.
- `references.bib` — bibliographie BibTeX pour archivage et réutilisation.

## Doctrine de citation

1. Une référence est citée à la première introduction substantielle d'une méthode, d'un standard ou d'une source.
2. Les résultats propres à Nostra AI restent sourcés par les artefacts HilmarCorp ; une référence académique externe ne remplace jamais la preuve quantitative interne.
3. Les documents de fournisseurs et standards sont cités pour documenter une interface, un format ou une convention, non pour certifier la qualité économique des données ou du modèle.
4. Les URL et DOI sont conservés dans le registre de référence afin d'assurer la traçabilité documentaire.
