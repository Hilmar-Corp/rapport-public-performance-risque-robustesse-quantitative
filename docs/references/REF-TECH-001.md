# REF-TECH-001 — Standards et documentation technique

## R-TECH-01 — SHA-256

**National Institute of Standards and Technology (NIST).** *FIPS PUB 180-4 — Secure Hash Standard (SHS).* DOI: 10.6028/NIST.FIPS.180-4.

Usage : définition normative de la famille SHA-2 utilisée pour les empreintes SHA-256 mentionnées dans le rapport.

## R-TECH-02 — SPDX

**SPDX Project / Linux Foundation.** *SPDX Specification.* Standard international ISO/IEC 5962:2021.

Usage : format de nomenclature logicielle mentionné dans la Partie X.

## R-TECH-03 — CycloneDX

**OWASP Foundation / Ecma International.** *CycloneDX Specification.*

Usage : format de nomenclature logicielle mentionné dans la Partie X.

## R-TECH-04 — OCI

**Open Container Initiative.** *OCI Image Format Specification.*

Usage : format de l'image OCI canonique et références par digest utilisées dans les contrôles de reproduction.

## R-TECH-05 — GitHub Artifact Attestations

**GitHub Docs.** *Artifact attestations.*

Usage : documentation du mécanisme d'attestation de provenance mentionné dans la chaîne de publication.

Note : les standards et documentations techniques sont cités pour documenter la technologie ou le format utilisé. Leur citation ne constitue pas une certification du dépôt HilmarCorp.
