# Périmètre de publication

## Contenu public distribué par GitHub

Le dépôt distribue :

- le code d’évaluation et de comptabilisation ;
- les stratégies publiques de référence ;
- les tests et contrôles qualité ;
- les courbes de valeur liquidative et de drawdown des références publiques ;
- les métriques agrégées des stratégies évaluées ;
- les métadonnées méthodologiques et d’intégrité.

## Niveau de divulgation de Nostra

Nostra AI reste propriétaire.

GitHub contient uniquement les métriques agrégées de Nostra et un engagement SHA-256. Il ne contient aucune série temporelle ni aucune trace d’exécution de Nostra.

## Publication sur le site internet

Un processus séparé destiné au site internet peut afficher des points quotidiens de valeur liquidative avec retard. Cet artefact n’est pas inclus dans GitHub et doit imposer un délai minimal de quatorze jours.
