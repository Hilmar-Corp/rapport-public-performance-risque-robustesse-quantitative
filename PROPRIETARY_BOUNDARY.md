# Frontière propriétaire

Le dépôt public exclut :

- la logique du modèle Nostra ;
- les caractéristiques, pondérations et paramètres du modèle ;
- les sorties probabilistes ;
- les positions quotidiennes de Nostra ;
- les rendements quotidiens de Nostra ;
- les séries quotidiennes de valeur liquidative et de drawdown de Nostra ;
- les traces de rotation et de coûts de transaction ;
- les transformations privées de données ;
- l’infrastructure de production et les identifiants d’accès ;
- les chemins privés vers les sources ;
- les modèles sérialisés ;
- les traces internes de recherche ;
- l’artefact de données utilisé pour les graphiques du site internet.

Le dépôt public peut inclure :

- le code source des stratégies publiques de référence ;
- les tests et contrôles de validation ;
- les métriques agrégées de Nostra ;
- les courbes quotidiennes des stratégies publiques de référence ;
- les métadonnées méthodologiques ;
- les manifestes cryptographiques ;
- un engagement SHA-256 portant sur l’artefact privé d’évaluation conservé.

Aucune série temporelle de Nostra n’est distribuée par GitHub.
