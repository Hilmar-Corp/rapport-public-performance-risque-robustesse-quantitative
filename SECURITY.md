
# Security Policy

## Supported releases

Security corrections apply to the latest controlled release and to `main`.

## Reporting

Do not publish security findings in a public issue.

Send a confidential report to `contact@hilmar-corp.com` containing the
affected commit, reproduction steps, expected impact and proposed remediation.

## Proprietary boundary

This repository must never receive proprietary Nostra AI logic, features,
parameters, probabilities, positions, daily returns, transaction-cost traces,
production credentials or private evaluation datasets.
