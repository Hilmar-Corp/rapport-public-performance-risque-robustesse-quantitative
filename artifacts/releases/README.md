# Publications contrôlées et versionnées

Chaque répertoire devient immuable après la publication de la version GitHub qui lui est associée.

`v0.2.0` constitue la première publication publique renforcée selon des exigences institutionnelles.

Le répertoire mutable `artifacts/latest` peut évoluer dans de futurs commits, tandis qu’un répertoire versionné doit rester strictement identique, octet par octet, à la publication correspondante.
