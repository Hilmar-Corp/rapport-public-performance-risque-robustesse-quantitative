# Artefacts publics contrôlés

Le répertoire `latest` contient la publication GitHub contrôlée courante.

Il comprend les courbes des références publiques, les métriques agrégées, les métadonnées méthodologiques, les manifestes d’intégrité et un engagement cryptographique portant sur l’artefact privé d’évaluation de Nostra conservé.

Il ne contient aucune série temporelle quotidienne ni aucune donnée d’exécution de Nostra.
