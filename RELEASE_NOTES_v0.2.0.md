# Rapport public de performance, de risque et de robustesse quantitative de Nostra AI - v0.2.0

Cette publication établit la première surface publique d’évaluation renforcée selon des exigences institutionnelles.

## Contrôles

- code source des stratégies publiques de référence sous licence Apache-2.0 ;
- artefacts de performance contrôlés soumis à un régime distinct de droits réservés ;
- aucune série temporelle ni aucune trace d’exécution de Nostra dans GitHub ;
- résultats agrégés de Nostra classés `artifact-verified` ;
- plage d’exposition gouvernée de Nostra explicitement comprise entre -10 % et +100 % ;
- plage d’exposition des références publiques comprise entre 0 % et 100 % ;
- réexécution déterministe des stratégies publiques à partir de l’artefact public engagé ;
- contraintes exactes de dépendances pour Python 3.13 ;
- intégration continue sous Python 3.11, 3.12 et 3.13 sur Ubuntu, ainsi que sous Python 3.13 sur macOS ;
- seuil de couverture tenant compte des branches fixé à 90 % ;
- manifestes SHA-256 et détection des altérations ;
- audit des vulnérabilités des dépendances ;
- nomenclature CycloneDX des dépendances ;
- CodeQL ;
- références immuables des actions GitHub ;
- artefacts contrôlés et versionnés.

Cette publication ne constitue pas une validation externe indépendante de Nostra AI.
